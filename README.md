# Ghazal Invitation

An illustrated Arabic wedding invitation built with React, TypeScript and Vite.

## Development

Run `npm ci`, then `npm run dev`. Run `npm run lint` and `npm run build` before deployment.

Wedding content lives in `src/invitation.config.ts`. Watercolor artwork lives in `public/assets/new-theme/`; composition styles are in `src/styles/watercolor.css`.

Repository: https://github.com/ahmadhlawa/ghazal-invitation

For Vercel, import this repository as `ghazal-invitation`, using the Vite preset, `npm run build`, and output directory `dist`. This checkout contains no Vercel project link or authentication. The existing hosted project's name and domains must be migrated in the authenticated Vercel account.
